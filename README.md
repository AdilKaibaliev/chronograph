# CHRONOGRAPH — Хронография

Интерактивная история Евразии, 610–1299 годы. Версия 1.0 RC3.8.

Карта государств, хронология событий, параллельный ход истории и современники в разделе «Звёзды Ислама». Русский интерфейс, исламская номенклатура, отдельная кыргызская историческая линия.

## Запуск

Откройте `index.html` в браузере. Сайт автономный, без установки зависимостей и этапа сборки. Для Vercel используется статическая публикация корневой папки.

В `downloads/chronograph_1_0_rc3_8.zip` находится архив этой версии.

## Данные

Границы приблизительны. Между историческими срезами показывается последний доступный контур; его дата указана в карточке. Даты жизни приведены по григорианскому календарю, в скобках — по хиджре. Источники указаны текстом в приложении.

Результаты функциональной проверки находятся в `verification.txt`. Полная историческая сверка данных продолжается.

## Дальнейшее развитие

- Подключение собственного домена.
- Английская и кыргызская версии с общей базой данных.
- Параллельная история Северной и Южной Америки, Австралии и расширение африканской истории.
- Постепенное расширение хронологии до 2025 года.
- Отдельный слой будущих событий по достоверным хадисам с указанием сборника, номера и оценки достоверности; без произвольно назначенных дат и мест.
