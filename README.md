## Просмотр

Откройте index.html или запустите локальный сервер из этой папки: python -m http.server 8773 --bind 127.0.0.1

[Локальный просмотр](http://127.0.0.1:8773/?lang=ru&year=1200&tab=compare). Кнопка «Мир» открывает общий обзор. Регион ограничивает подборку в панели, но остальные материки остаются видимыми на карте.

Новый вид «Общество» показывает три темы: власть, хозяйство и жизнь общества. Поиск помогает найти нужный профиль. Тексты соответствуют этапу выбранного года; при выборе территории на карте её учебные заметки также доступны в панели.

«Хронология» объединяет события, этапы и территориальные изменения. Доступны поиск, фильтры по веку и теме, переход к месту события и нижняя лента. Кнопки этапов позволяют увидеть изменение территории. Карта и управление временем помещаются в экран; подробности прокручиваются внутри правой панели.

Владения, влияние, культурные области, расселение и культурные ландшафты различаются. Контуры приблизительные, редакционно нарисованные. Названия источников в интерфейсе показаны без внешних ссылок. Исламская номенклатура сохранена.
