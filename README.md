# CHRONOGRAPH 1.4.1

Интерактивный исторический атлас Евразии, 610–1299 годы: Русский / English / Кыргызча.

Карта, 64 ключевых события, 72 исторических слоя и «Звёзды Ислама» используют общую историческую базу. Язык переключается без перезагрузки. Год, карта и вкладка сохраняются в адресе. Компактная страница с внутренней прокруткой правой панели и постоянно доступным воспроизведением.

Все 57 имён в «Звёздах Ислама» открывают индивидуальную краткую биографию на трёх языках. Внутри карточки можно перейти к современникам выбранного года. Биографические источники: TDV İslâm Ansiklopedisi; статьи указаны в каждой карточке. Проверки: `node scripts/biographies-test.cjs`.

Добавлен отдельный режим «Будущие события»: 78 тематических карточек по «Сахиху аль-Бухари» и «Сахиху Муслима», десять больших признаков, связанные последовательности, поиск и карта названных мест. Подробности охвата и источников: `scripts/future/README.md`.

Откройте `index.html` в браузере. Установка зависимостей не нужна. Для Vercel используется статическая публикация корневой папки. Архив: `downloads/chronograph_1_4_1.zip`.

Исходный атлас: `src/atlas.html`. Переводы и инструкции сборки: `scripts/i18n/README.md`. Результаты проверки: `verification.txt`.

Границы приблизительны; между срезами сохраняется последний доступный контур с указанием его даты. Даты жизни — по григорианскому календарю, в скобках по хиджре. Источники указаны текстом, без ссылок.

Перевод покрывает текущую версию. Редакторская вычитка кыргызского текста и полная историческая сверка остаются последующими задачами.

Дальнейший план: собственный домен; параллельная история обеих Америк, Австралии и Африки; постепенное продление до 2025 года; дальнейшая редакторская сверка тематического каталога хадисов и кыргызского перевода.

В версии 1.4 английский выбран для первого открытия; явный язык в адресе имеет приоритет, ручной выбор сохраняется в браузере. Кнопка поддержки на трёх языках открывает информационное окно. Получатель и способ перевода ещё не выбраны владельцем; приём денег не подключён.

Версия 1.4: датированные политические статусы кыргызов, отдельный слой расселения, 11 этапов истории и направления документированных перемещений; пересмотр монгольских владений и зависимых областей. Проверенные китайские главы, ограничения реконструкции и принципы датировки описаны в HISTORICAL_REVIEW.md. Проверка: `node scripts/history-test.cjs`.

Версия 1.4.1: общий монгольский вид по умолчанию и переключение на улусы; расширенная реконструкция кыргызского влияния с отдельным енисейским ядром; исправлен устаревший контур Тан для 840 года. Проверка общего вида: node scripts/unified-map-test.cjs.
