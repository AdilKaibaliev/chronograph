# Chronograph — исторический атлас

Локальная версия **1.13.0, 610–1939**, 1 октября 2026. Публичная версия: **1.7.1, 610–1789**. Новая сборка не опубликована.

## Изменения

- Современные границы включены по умолчанию и отключаются в «Слоях».
- Отдельная панель «Пути расширения» заменена слоем «Походы и освоение» на обычной карте, по образцу Шёлкового пути. 14 держав / 58 линий; США, Россия, Османы, Цин и Тимур. Линии появляются в годы событий, открывают описание и источники, сохраняют перетаскивание карты. См. EXPANSION_ROUTES_REVIEW.md.
- Новый обзор 1919–1939: послевоенные государства, СССР, Турецкая Республика, мандаты, кыргызская автономия и ССР, Китай и японская экспансия, Великая депрессия, колониальная Африка, Чакская война, доминионы и полярные исследования. Добавлены 27 профилей, 15 событий и биография Ибн Бадиса. См. TO1939_RELEASE_REVIEW.md.
- Сохранены единые имперские контуры, различия между провинциями, зависимостью и оккупацией, кыргызская линия, три языка и английский по умолчанию.
- Геометрия объединяется при сборке; браузер получает готовые контуры. Сохранены кеширование, пагинация, отложенное раскрытие списков и уменьшение подписей при отдалении. Прежние замеры performance-1918.json относятся к прежней версии.

Каталог: 463 профиля, 3150 этапов, 3156 региональных состояний, 565 политических контуров, 478 событий вместе с исходной хронологией, 573 группы источников, 89 биографий. Сами записи карты до 1919 года сохранены.

[Мир в 1939 году](http://127.0.0.1:8773/?lang=ru&year=1939&tab=compare&view=1.000%2C0.000%2C0.000).

[Поход Османов, 1517](http://127.0.0.1:8773/?lang=ru&year=1517&tab=compare).

Сборка: node scripts/i18n/build.cjs. Полная проверка: node scripts/release-check.cjs — сборка и 27 наборов проверок. Журналы: verification-interwar.txt, verification-interwar-browser.json.

Запуск из этой папки: python -m http.server 8773 --bind 127.0.0.1. На рабочем компьютере сервер уже запущен.

Панель прокручивается внутри экрана; шкала времени доступна постоянно. Источники в интерфейсе показаны названиями без внешних ссылок. Современные границы — географический ориентир, исторические владения отображаются отдельной заливкой.

Контуры схематические; малые анклавы и ежедневные линии фронтов не детализированы. Следующий отрезок: 1940–1945, далее 1946–1991 и 1991–2026.
