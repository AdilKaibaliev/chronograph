# CHRONOGRAPH 1.1 — Русский / English / Кыргызча

Переведены интерфейс, 57 ключевых событий, карточки 68 политических слоёв, региональные справки, параллельная история, существующие биографические справки 57 личностей, методология, источники и пояснения между ключевыми годами.

Одна историческая база для трёх языков. Переключение сохраняет год, положение карты и вкладку. Параметры lang, year, view, tab позволяют делиться выбранным состоянием.

## Сборка и проверка

Из корня репозитория, Node.js 20 или новее:

```
node scripts/i18n/build.cjs
node scripts/i18n/test.cjs
node scripts/i18n/audit.cjs
```

Сторонние зависимости не нужны. src/atlas.html содержит исходный атлас и общие данные; index.html — готовый автономный сайт. JSON и TXT содержат переводы. Нумерованные TXT ссылаются на неизменяемый remaining-base.json; дополнительные переводы аудита — на audit-base.json. compiled-messages.json генерируется при сборке.

Проверены 1168 строк словаря и динамические шаблоны. Аудит формирует тексты всех 690 годов, карточек 68 государств и 57 личностей: 147361 проверка, без остаточных русских фрагментов в английском выводе. Исторические данные, даты, геометрия и биографии сравниваются с базовой версией. Источники остаются обычным текстом.

В браузере проверены смена языков, сохранение года и вида карты, прямая ссылка на кыргызский региональный раздел, сравнение, источники, методология, биография, выбор государства и Play/Pause. На экране 390×844 страница помещается в экран, Play доступен; ошибок JavaScript не обнаружено.

Лингвистическая вычитка носителем кыргызского языка остаётся отдельной редакционной задачей. Перевод не заменяет полной исторической сверки исходной базы. Для личностей без подробной биографии сохранена хронологическая справка с соответствующим пояснением.
